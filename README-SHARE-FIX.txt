حل مشكلة مشاركة الكتب على فيسبوك

1) ارفع index.html إلى جذر مستودع GitHub Pages.
2) ارفع مجلد scripts ومجلد .github كما هما.
3) لا تحذف مجلد books؛ الـ GitHub Action سيولّد داخله صفحة مستقلة لكل كتاب.
4) الـ Action يعمل كل 15 دقيقة، وكذلك عند تعديل الملفات الأساسية، ويمكن تشغيله يدويًا من GitHub Actions.
5) عند مشاركة كتاب، الرابط سيكون /books/BOOK_ID.html. فيسبوك يقرأ Open Graph الخاص بالكتاب (الاسم، الوصف، الغلاف)، ثم عند فتح الرابط يتم تحويل الزائر إلى /?book=BOOK_ID&read=1 لفتح الكتاب مباشرة.

مهم: هذا الحل يفترض أن Realtime Database يسمح بالقراءة العامة للـ books، لأن الموقع نفسه يقرأ الكتب من المتصفح. إذا كانت قواعد Firebase تمنع القراءة العامة، يجب تعديل قواعد القراءة أو استخدام Secret/Token في GitHub Actions بدل الرابط العام.
