# 📚 المنصة الأدبية الرسمية للكاتب سعيد الشوادفي

منصة أدبية متكاملة وموقع ويب تفاعلي يستعرض الأعمال الروائية والقصصية للكاتب والروائي **سعيد الشوادفي**، بالإضافة إلى تقديم خدمات أدبية، ورش تدريبية، ومتجر للمنتجات الرقمية والمقالات الأدبية، مع لوحة تحكم شاملة لإدارة المحتوى.

## ✨ مميزات المنصة

### 🌍 واجهة المستخدم (User Interface)
* **المكتبة الرقمية والأعمال الأدبية:** تصفح الروايات والقصص والشعر، مع إمكانية القراءة المباشرة المقسمة إلى فصول، أو طلب النسخ الورقية والرقمية.
* **المكتبة الصوتية والمرئية:** إلقاء صوتي ومقاطع مسموعة (MP3) مع حلقات كرتونية وفيديوهات مرئية.
* **الخدمات والدورات:** حجز ورش العمل والدورات التدريبية والاستشارات الأدبية.
* **متجر المنتجات الرقمية:** بيع وتحميل الكتب الرقمية والمنتجات الإبداعية.
* **نظام دعم الكاتب (رعاية فصل):** دعم مالي مباشر مدمج بالموقع عبر (فودافون كاش، إنستا باي InstaPay، والمحافظ البنكية الإلكترونية).
* **تقديم طلبات النشر:** نموذج تفاعلي يتيح للكتاب الآخرين رفع أعمالهم (PDF) وتقديم طلبات نشر لمراجعتها.
* **نظام التفاعل:** إمكانية ترك القراء لآرائهم ومراجعاتهم وتقييم الفصول والأعمال.
* **المظهر والوضع الليلي:** دعم كامل للوضع الليلي (Dark Mode) بألوان مريحة للعين (نبيتي غامق وذهبي).

### 🛠 لوحة تحكم الكاتب الشاملة (Admin Dashboard)
* **إحصائيات حية:** تتبع العداد الإجمالي لزوار الموقع وإجمالي قراءات الكتب.
* **التحكم البصري والمظهر:** إمكانية تعديل ألوان الواجهة (الوضع الليلي والنهاري) وتغيير صور الغلاف واللوجو النصي مباشرة.
* **إدارة المحتوى:** إضافة وتعديل وحذف (الأعمال الأدبية، الصوتيات، الفيديوهات، الورش، المنتجات الرقمية، المقالات).
* **إدارة طلبات النشر:** استقبال ومراجعة ملفات الـ PDF وبيانات الكتاب المتقدمين بطلبات نشر.

## 📖 أبرز الأعمال الإبداعية بالمنصة

تضم المنصة مجموعة من الإصدارات البارزة للكاتب والتي حققت حضوراً لافتاً في ساحة الغموض والتشويق، ومنها:
* **رواية "ظلال لا تنام"** 🕵️‍♂️ - رحلة حبس الأنفاس بين أغوار النفس البشرية وأسرارها المخبأة.
* **رواية "ابن الغزال"** 🦌 - حبكة درامية مشوقة تمزج بين الغموض والدراما الإنسانية العميقة.
* **نخبة مميزة من الإصدارات القصصية** 🎨 - أعمال إبداعية تدمج بليغاً بين الفن الأدبي والتصميم البصري.

---

## 🛠 التقنيات المستخدمة (Tech Stack)

* **Front-End:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Backend & Database:** Firebase (Authentication & Realtime Database / Firestore) لتسجيل الدخول الآمن للوحة التحكم وحفظ إحصائيات القراء والبيانات.
* **Responsive Design:** متوافق تماماً مع شاشات الهواتف الذكية، الأجهزة اللوحية، وأجهزة الحاسوب.

## 🚀 تشغيل المشروع محلياً (للمطورين)

إذا كنت مبرمجاً وترغب في تحميل كود المنصة وتجربته محلياً على جهازك، اتبع الخطوات التالية:

1. قم بعمل استنساخ (Clone) للمستودع:
   ```bash
   git clone https://github.com
   ```
2. افتح مجلد المشروع على جهازك.
3. قم بتشغيل ملف `index.html` عبر أي متصفح، أو باستخدام إضافة **Live Server** في برنامج VS Code.
